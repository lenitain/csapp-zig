# Data Lab

**对应章节：** 第二讲（数据表示）

**一句话点题：** 位运算可以实现算术运算、条件判断、类型转换——知道这一点就够了。

## 为什么要做这个实验

CSAPP 的 Data Lab 让你用有限的位运算符（不能用 if、不能用循环、不能用乘除）实现各种函数：整数取反、条件判断、绝对值、浮点数操作……

这个实验的**核心 insight** 不是每个函数怎么解，而是：

**位运算是一套完备的计算基础。** 加法可以用异或和与实现，乘法可以用移位和加法实现，条件判断可以用位掩码实现。你不需要 if/else，不需要算术运算符，纯位运算就能做任何事。

为什么这很重要？因为 CPU 的 ALU 就是这么工作的——加法器、移位器、逻辑门，这些基本单元组合起来就能做一切。

## 经典题目：只用位运算实现条件判断

### 问题

```c
// 只用 ~, &, ^, |, <<, >>, !, +
// 实现：如果 x == y 返回 1，否则返回 0
int is_equal(int x, int y) {
    // 你的实现
}
```

### 解答

```c
int is_equal(int x, int y) {
    return !(x ^ y);
}
```

### 思路

`x ^ y`：如果 x 和 y 的每一位都相同，结果为 0；否则不为 0。`!0` 得到 1，`!非零` 得到 0。

就这么简单。**异或检测"不同"，取反得到"是否相同"。**

## 经典题目：只用位运算实现算术取反

### 问题

```c
// 只用 ~, &, ^, |, <<, >>, !, +
// 实现：返回 -x
int negate(int x) {
    // 你的实现
}
```

### 解答

```c
int negate(int x) {
    return ~x + 1;
}
```

### 思路

补码的定义：`-x = ~x + 1`。这不是技巧，这是补码的数学性质。Data Lab 让你用这个性质，但更重要的是让你**理解**这个性质。

## 经典题目：只用位运算实现绝对值

### 问题

```c
// 只用 ~, &, ^, |, <<, >>, !, +
// 实现：返回 |x|（如果 x 是 TMin，返回 TMin）
int abs_val(int x) {
    // 你的实现
}
```

### 解答

```c
int abs_val(int x) {
    int mask = x >> 31;        // x < 0 时 mask = 0xFFFFFFFF，否则 mask = 0
    return (x ^ mask) + (~mask + 1);  // 等价于 (x ^ mask) - mask
}
```

### 思路

如果 x 是负数，需要返回 -x = ~x + 1。如果 x 是正数，直接返回 x。

`mask = x >> 31`：算术右移 31 位，如果是负数得到全 1（0xFFFFFFFF），如果是正数得到全 0。

`x ^ mask`：如果 mask 全 1，结果是 ~x；如果 mask 全 0，结果是 x。

`+ (~mask + 1)`：如果 mask 全 1，加 -1（相当于减 1）；如果 mask 全 0，加 0。

组合起来：负数时得到 ~x - 1 = -(x+1) - 1 = -x；正数时得到 x。

**核心 insight：用位掩码实现"无分支条件"。** 这在硬件层面很重要——分支有预测失败的代价，位运算没有。

## 经典题目：浮点数位操作

### 问题

```c
// 返回 float f 的位级表示
// 浮点数规则：(-1)^s × 1.fraction × 2^(exponent - bias)
unsigned float_bits(float f) {
    // 你的实现（不能用 union 或指针转换）
}
```

### 解答

```c
unsigned float_bits(float f) {
    unsigned bits;
    // 真正的做法是用 memcpy
    memcpy(&bits, &f, sizeof(unsigned));
    return bits;
}
```

### 思路

C 标准不允许通过指针类型转换来重新解释浮点数的位（严格别名规则）。正确的方式是用 `memcpy`——编译器会把它优化成零开销的寄存器移动。

这个题目真正想让你理解的是：**float 的位级表示和 int 的位级表示是不同的解释方式，但底层是同一堆比特。**

## 本实验的 takeaway

1. 位运算是一套完备的计算基础——加法、乘法、条件判断都可以用位运算实现
2. 补码的性质（`-x = ~x + 1`）不是技巧，是数学
3. 无分支条件（位掩码）避免了分支预测失败的代价
4. 浮点数和整数在位级上是同一堆比特，只是解释不同

**在 AI 时代，你不需要手写这些位运算 hack。但你需要理解"位运算能做什么"——这是理解 CPU、编译器优化、安全漏洞的基础。**
